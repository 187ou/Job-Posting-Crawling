# 招聘市场分析工具

基于终端的智联招聘数据采集与分析工具。

## 功能特性

- **数据采集**：使用 `curl_cfi` 实现 TLS 指纹伪装，支持多线程并发采集。
- **终端分析面板**：六合一分析面板，涵盖薪资分布、热门技能、城市分布、行业分布、经验-薪资关系、学历要求。
- **数据导出**：自动解析薪资字段，输出包含 **38 个结构化字段** 的 CSV 文件（中文表头）。
- **可视化图表**：自动生成 6 张 Plotly 图表并保存为 PNG 图片。
- **AI 分析（可选）**：支持接入 OpenAI 兼容的 API，获取市场洞察报告。

## 快速开始

**需要 Python 3.10 及以上版本**

```bash
pip install -r requirements.txt
python main.py
```

## 大数据量采集（20w+ 条）

智联招聘单关键词上限约 50 页 / 1000 条，要采集 20w+ 需要大量不同关键词。工具内置关键词自动扩展：

**方法 1：文件批量加载**

创建 `keywords.txt`（每行一个，逗号分隔也行，`#` 注释）：

```
Python
Java
前端
数据分析
AI
测试
运维
产品经理
UI设计
C++
Go
嵌入式
```

运行后在 "关键词文件路径" 输入文件路径。

**方法 2：自动扩展**

输入少量种子词（甚至 1 个），在提示 "自动扩展关键词？" 时确认，工具会通过同义词变体 + 城市组合将种子展开为几百个关键词。

**示例**：10 个种子词 → 扩展为 500 个关键词 → 约 25w 条数据

| 配置 | 请求数 | 预计耗时 |
|---|---|---|
| 500 关键词 × 50 页, delay=0.8s, 8 并发 | 25,000 | ~55 分钟 |
| 500 关键词 × 50 页, delay=1.5s, 6 并发 | 25,000 | ~110 分钟 |

> 超过 5000 条自动启用流式写盘，内存安全，中途崩溃数据不丢。

## 项目结构

```
├── main.py                      # 程序入口
├── pyproject.toml               # 项目元数据与依赖
├── requirements.txt             # pip 依赖清单
├── keywords.txt                 # 关键词文件（自行创建）
├── app/
│   ├── scraper.py               # 采集引擎（流式写盘 + 增量统计）
│   ├── keyword_expander.py      # 关键词自动扩展器
│   ├── charts.py                # 图表生成（Plotly）
│   ├── anti_bot.py              # 反爬策略（4 档速度预设）
│   ├── utils.py                 # 工具函数
│   ├── paths.py                 # 路径管理
│   └── parsers/
│       └── zhaopin.py           # 智联招聘数据解析器（JSON + HTML）
└── output/                      # 运行时自动生成
```

## 技术说明

- **数据源**：从智联招聘列表页 HTML 内嵌的 `__INITIAL_STATE__ JSON` 一次性提取完整职位数据（含描述、坐标、福利等），无需额外请求详情页
- **招聘者信息**：通过 HTML 选择器从列表页提取 HR 姓名与职位
- **薪资解析**：支持 `万/月`、`元/月`、`K` 等多种格式，自动转换为数值
